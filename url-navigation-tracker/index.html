URL Navigation Tracker

Capture observable URL navigation events, redirects, and History API changes in a private local timeline.

Find it on the Chrome Web Store

What it captures

  • Rapid navigation steps and observable redirect destinations
  • JavaScript navigation and History API changes
  • URL fragment changes and iframe navigation
  • Tab, frame, timestamp, transition, and request metadata when Chrome provides it

Local by design

Captured URLs are stored in Chrome on your device. The extension does not send browsing data to an external server, use analytics, show ads, or modify Chrome's standard browsing history.

Support

For installation help, reload the unpacked extension from chrome://extensions, then open the popup on the tab being tested. Choose All tabs if a navigation opens a new tab.
