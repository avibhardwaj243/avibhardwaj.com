URL Navigation Tracker Privacy Policy

Last updated: November 28, 2026

Data collected

URL Navigation Tracker collects URLs and related navigation metadata that Chrome exposes to the extension, including timestamps, tab IDs, frame IDs, event types, transition details, document identifiers, and redirect or request identifiers when available.

How data is used

The data is used only to provide the extension's local navigation timeline, search, copy, filtering, and export features.

Storage and sharing

Data is held temporarily in Chrome using chrome.storage.session, which keeps it in memory for the browser session and does not persist it to disk. The capture buffer is cleared after a successful copy, when Chrome restarts, or when the extension is reloaded. URL data is not transmitted to or shared with external servers or third parties. The extension does not use analytics, advertising, or tracking services.

Limitations

Chrome internal pages, restricted URLs, and network activity that Chrome does not expose to extensions cannot be captured.
